# 한 수 — HTML 장기

`index.html`을 브라우저에서 열면 바로 실행됩니다. 빌드·패키지 설치·인터넷 연결이 필요하지 않습니다.

로컬 서버로 실행하려면:

```sh
python3 -m http.server 8765
```

브라우저에서 http://localhost:8765 에 접속하세요.

## 기능

- 컴퓨터 대전: 초로 플레이, 2-ply 탐색을 사용하는 입문용 컴퓨터
- 친구와 대전: 한 화면에서 번갈아 두는 2인 모드
- 이동 가능 위치, 마지막 수, 장군 표시
- 무르기 (컴퓨터 대전에서는 내 수와 컴퓨터 응수를 함께 취소)
- 기보 및 잡은 말, 판 뒤집기, 두 가지 마·상 배치
- 키보드 방향키 / Enter / Space 조작과 모바일 대응
- 진행 중 새 대국 또는 모드 변경 시 초기화 확인

## 규칙

[PyChess 장기 설명](https://www.pychess.org/variants/janggi)을 참고한 친선 규칙입니다. 마·상의 멱, 포의 넘는 말 제한, 궁성 대각선, 자충 금지, 장군과 외통수를 적용합니다. 초가 먼저 둡니다.

빅장에서는 해소하는 수를 두거나 한 수 쉼으로 무승부를 수락합니다. 연속 두 번 쉼과 같은 국면·차례의 세 번째 반복은 무승부입니다. 대회식 점수 판정, 온라인 대전, 새로고침 후 저장은 지원하지 않습니다. 배치 선택은 다음 새 대국에 적용됩니다.

## 검증

```sh
node engine.test.js
node --check app.js
```

실제 Chrome에서 컴퓨터 응수, 무르기, 모드 전환, 연속 쉼 무승부, 도움말, 판 뒤집기를 확인했습니다. 1440px / 768px / 390px에서 가로 넘침이 없음을 확인했습니다. 화면과 로그는 `qa/`에 있습니다. Lighthouse 점수 감사는 수행하지 않았습니다.

구성: `engine.js`는 독립 규칙 엔진, `app.js`는 게임 상태 및 조작, `style.css`는 반응형 화면입니다.
